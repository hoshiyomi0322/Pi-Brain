# Finite-State Transducer (FST)
- ### 5-Tuple：$M = \langle Σ,~Γ,~Q,~δ,~λ \rangle$
    - $Q$ = a set of states
    - $Σ$ = Input [Alphabet](/stem/it/computer-science/theory-of-computation/automata-theory-and-formal-languages/automata-theory-and-formal-languages.md#alphabet)
    - $δ$ = [State Transition Function](../finite-state-machine.md#state-transition-function-)
    - $Γ$ = Output [Alphabet](/stem/it/computer-science/theory-of-computation/automata-theory-and-formal-languages/automata-theory-and-formal-languages.md#alphabet)
    - $λ$ = [Output Function](../finite-state-machine.md#output-function-)
- ### Types of Finite-state Transducer
    |Finite-state Transducer|[Output Function](../finite-state-machine.md#output-function-)|
    |:---:|:---:|
    |[Moore Machine](#moore-machine)|$λ:Q \to Γ$|
    |[Mealy Machine](#mealy-machine)|$λ:Q \times Σ \to Γ$|
