# Finite State Acceptor
- ### 5-Tuple：$M = \langle Q,~Σ,~δ,~q_0,~F \rangle$
    - $Q$ = a set of states
    - $Σ$ = Input <a href="/stem/it/computer-science/theory-of-computation/automata-theory-and-formal-languages/automata-theory-and-formal-languages.md#alphabet">Alphabet</a>
    - $δ$ = <a href="../finite-state-machine.md#state-transition-function-">State Transition Function</a>
    - $q_0$ = Start State ($q_0\in Q$)
    - $F$ = a set of Accept States ($F\subseteq Q$)
- ### Types of Finite State Acceptor
    |Finite State Acceptor|[State Transition Function](../finite-state-machine.md#state-transition-function-)|
    |:---:|:---:|
    |[Deterministic Finite Automata (DFA)](#deterministic-finite-automata-dfa)|$δ:Q \times Σ \to Q$|
    |[Nondeterministic Finite Automata (NFA)](#nondeterministic-finite-automata-nfa)|$δ:Q \times Σ \to \mathcal{P}\left(Q\right)$|
