# Sequence
- ### Definition：an ordered collection of objects
- ### Properties of Sequence
    |Properties of Sequence|Definition|Example|
    |:---:|:---:|:---:|
    |Orderedness|the elements have a specific order|$\left(1,~2,~3\right) \ne \left(3,~1,~2\right)$|
    |Repetition|the elements can be repeated|$\left(1,~2,~2,~3\right)$|

# Number Sequence
- ### Definition：a finite sequence of characters from a finite set (an alphabet)
- ### Recurrence Relation
- ### Arithmetic Sequence (Arithmetic Progression)：$a_1,~a_1+d,~a_1+2d,~a_1+3d,~\cdots$ {#arithmetic-sequence}
    - $a_n=a_1+\left(n-1\right)d$
    - $d=\text{common difference}$
    - [Arithmetic Series](/stem/math/series.md#arithmetic-series)
- ### Geometric Sequence (Geometric Progression)：$a_1,~a_1r,~a_1r^2,~a_1r^3,~\cdots$ {#geometric-sequence}
    - $a_n=a_1\times r^{\left(n-1\right)}$
    - $r=\text{common ratio}$
    - [Geometric Series](/stem/math/series.md#geometric-series)
