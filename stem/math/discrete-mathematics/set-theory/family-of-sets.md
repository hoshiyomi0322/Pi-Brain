# Family of Sets
- ### Definition：a collection of different sets
- ### Example：$\set{\set{1},~\varnothing,~\set{a,~b,~c}}$

# Indexed Family

# Partition of a Set
- ### Partition of $S$：a collection of non-empty, pairwise disjoint subsets of $S$ whose union equals $S$
- ### Example
    - $S=\set{a,~b,~c}$
    - Partition of $S$：$\set{\set{a},~\set{b},~\set{c}},~\set{\set{a,~b},~\set{c}},~\set{\set{a,~b,~c}},~\cdots$

# Power Set
- $\mathcal{P}\left(S\right)$：the set of all subsets of a set $S$
- ### [Cardinality](#set) of Power Set：$|\mathcal{P}\left(S\right)|=2^{|S|}$
    - #### Cantor's Theorem：$|\mathcal{P}\left(S\right)|>|S|$
- ### Example
    - $S=\set{a,~b,~c}$
    - $\mathcal{P}\left(S\right)=\set{\varnothing,~\set{a},~\set{b},~\set{c},~\set{a,~b},~\set{a,~c},~\set{b,~c},~\set{a,~b,~c}}$
    - $|\mathcal{P}\left(S\right)|=2^3=8$
