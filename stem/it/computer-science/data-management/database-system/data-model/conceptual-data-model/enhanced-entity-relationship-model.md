# Key Concepts and Features
- ### Superclass and Subclass
    - Superclass (Supertype)：higher-level entity {#superclass}
    - Subclass (Subtype)：lower-level entity {#subclass}
- ### Inheritance
    - Attribute inheritance：[subclasses](#subclass) inherit attributes from [superclasses](#superclass)
    - Relationship Inheritance：[subclasses](#subclass) inherit relationships from [superclasses](#superclass)
    - Overriding Inheritance
    - Participation inheritance
- ### Specialization and Generalization
    |Concepts and features|Definition|Schema Size|
    |:---:|:---:|:---:|
    |**Specialization**|a top-down approach where the [superclass](#superclass) is subdivided into two or more [subclasses](#subclass)|Increase|
    |**Generalization**|a bottom-up approach where multiple entities with common characteristics are combined into a [superclass](#superclass)|Reduce|
