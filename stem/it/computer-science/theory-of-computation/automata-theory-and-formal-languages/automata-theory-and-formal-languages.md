# Automata Theory and Formal Languages
- ### Alphabet ($Σ$)：a finite set of symbols {#alphabet}
- ### String (w)：a finite sequence of symbols formed from an alphabet {#string}
- ### Language (L)：a set of strings generated by specific rules {#language}
- ### Grammar：a set of production rules used to generate the strings of a language {#grammar}
- ### Automata：an abstract machines that act as language acceptors to determine if an input string belongs to a specific language {#automata}
