# Parity bit
- ### Parity
    |Parity|Definition|
    |:---:|:---:|
    |Even Parity|ensure the total number of 1-bits (including the parity bit) is Even|
    |Odd Parity|ensure the total number of 1-bits (including the parity bit) is Odd|
    - #### Parity bit
        |Total number of 1-bits|Even Parity bit|Odd Parity bit|
        |:---:|:---:|:---:|
        |Even|0|1|
        |Odd|1|0|
- ### Example
    |3 bits of data|Total number of 1-bits|4 bits including Even Parity|4 bits including Odd Parity|
    |:---:|:---:|:---:|:---:|
    |000|0 (Even)|000**0**|000**1**|
    |010|1 (Odd)|010**1**|010**0**|
    |101|2 (Even)|101**0**|101**1**|
    |111|3 (Odd)|111**1**|111**0**|
