# Change Directory (cd)
- ### Command
    |Command|Description|
    |:---:|:---:|
    |`cd <path>`|Move to `path`|
    |`cd -`|Move back to the previous directory|

# Move (mv)
- ### Command
    |Command|Description|Example|
    |:---:|:---:|:---:|
    |`mv [options...] [files...] [destination_folder]`|Move files to `destination_folder`|`mv a.txt src/`, `mv a.jpg b.png src/dir/`, `mv *.c cpp/`|
    |`mv [options...] [file] [new_filename]`|Rename a file to `new_filename`|`mv old.txt new.txt`|
- ### Options
    |Options|Description|
    |:---:|:---:|
    |`-i`||
    |`-n`||
    |`-f`||
    |`-v`||
    |`-u`||

# Copy (cp)
- ### Command
    |Command|Description|Example|
    |:---:|:---:|:---:|
    |`cp [options...] [files...] [destination_folder]`|Copy files to `destination_folder`|`cp a.txt src/`, `cp a.jpg b.png src/dir/`, `cp *.c cpp/`|
    |`cp [options...] [file] [new_filename]`|Copy a file with a `new_filename`|`cp old.txt new.txt`|
- ### Options
    |Options|Description|
    |:---:|:---:|
    |`-r`||

# Remove (rm)
- ### Command
    |Command|Description|Example|
    |:---:|:---:|:---:|
    |`rm [options...] [files...]`|Remove files|`rm -f a.txt`|
    |`rm -r [options...] [folder]`|Recursively remove a folder|`rm -rf /`|
- ### Options
    |Options|Description|
    |:---:|:---:|
    |`-f`|Force remove|
    |`-i`||
