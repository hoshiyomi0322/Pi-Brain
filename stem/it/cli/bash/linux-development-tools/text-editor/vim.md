# Vi IMproved (Vim)
|Command|Description|
|:---:|:---:|
|`vim <file>`|Open or create file|
|`Esc`|Return to Normal Mode|
|`:w`|Write|
|`:q`|Quit|
|`:wq`|Write and Quit|
|`:q!`|Quit without write|
|`:x`|Exit, same as `:wq`|
|`i`|Start [Inserting](#insert-mode) before the current cursor|
