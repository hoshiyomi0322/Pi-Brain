# Tcpdump
|Command|Description|
|:---:|:---:|
|`tcpdump [options...] [filter_expressions]`|
- ### Options
    |Options|Description|
    |:---:|:---:|
    |`-i`||

# Filter Expressions
- ### Host
    |Filter Expressions|Description|
    |:---:|:---:|
    |`host <ip>`||
    |`src host <ip>`||
    |`dst host <ip>`||
- ### Port
    |Filter Expressions|Description|
    |:---:|:---:|
    |`port <port_number>`||
    |`src port <port_number>`||
    |`dst port <port_number>`||
- ### Protocol
    |Filter Expressions|Description|
    |:---:|:---:|
    |`tcp`|
    |`udp`|
    |`icmp`|
- ### [Logical Operator](/stem/math/discrete-mathematics/mathematical-logic/mathematical-logic.md#logical-connective-logical-operator)
    |Logical Operator|Description|
    |:---:|:---:|
    |`and`, `&&`|AND|
    |`or`, `\|\|`|OR|
    |`not`, `!`|NOT|
