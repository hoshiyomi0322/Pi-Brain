# AVL Tree
- ### Balance Factor (BF) = 左子樹高度-右子樹高度
	|Balance Factor|Balance|
    |:---:|:---:|
    |$|BF|<2$|balanced|
	|$|BF|\geq2$|unbalanced|
- ### Rotation (rebalancing)：將不平衡旋轉成平衡
	|Direction|Rotation|
    |:---:|:---:|
    |Left Left (LL)|右旋|
	|Right Right (RR)|左旋|
	|Left Right (LR)|左旋→右旋|
	|Right Left (RL)|右旋→左旋|
