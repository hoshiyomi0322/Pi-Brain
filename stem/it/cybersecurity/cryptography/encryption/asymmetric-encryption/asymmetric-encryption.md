# Asymmetric Encryption
- ### Key
    - #### Public key
    - #### Private key
- ### Encrypt：$\text{Plaintext} \xrightarrow{\text{public key}} \text{Ciphertext}$
- ### Decrypt：$\text{Ciphertext} \xrightarrow{\text{private key}} \text{Plaintext}$
