# Asymmetric Encryption
- ### Key
    - #### Public key
    - #### Private key
- ### Encrypt：$`\text{Plaintext} \overset{\text{public key}}{\longrightarrow} \text{Ciphertext}`$
- ### Decrypt：$`\text{Ciphertext} \overset{\text{private key}}{\longrightarrow} \text{Plaintext}`$
