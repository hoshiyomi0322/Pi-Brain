# Symmetric Encryption
- ### Key
    - #### Session Key
- ### Encrypt：$`\text{Plaintext} \overset{\text{key}}{\longrightarrow} \text{Ciphertext}`$
- ### Decrypt：$`\text{Ciphertext} \overset{\text{key}}{\longrightarrow} \text{Plaintext}`$
