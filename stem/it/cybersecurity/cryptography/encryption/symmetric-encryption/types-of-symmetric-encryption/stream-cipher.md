# XOR Cipher
- ### $\left( A\oplus B \right) \oplus B = A$
    - #### $A$ = Plaintext
    - #### $B$ = Key
    - #### $A\oplus B$= Ciphertext
- ### Encrypt：$A \xrightarrow{\oplus B} A\oplus B$
- ### Decrypt：$A\oplus B \xrightarrow{\oplus B} A$
