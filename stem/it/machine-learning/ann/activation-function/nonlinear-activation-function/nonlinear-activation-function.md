# Saturating, Non-Saturating
- ### [Saturating Activation Function](saturating-activation-function.md)
    - $`\lim\limits_{\left|z\right| \to \infty}{\left|\nabla f\left(z\right)\right|} = 0`$
- ### [Non-Saturating Activation Function](non-saturating-activation-function.md)
    - $`\lim\limits_{\left|z\right| \to \infty}{\left|\nabla f\left(z\right)\right|} \ne 0`$

# Softmax Activation Function
- Converts raw output scores into probability distributions for multi-class classification problems
