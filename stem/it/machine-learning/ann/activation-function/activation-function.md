# Activation Function
- ### $`z=\sum{\left(wx+b\right)}`$
    - $`x=input`$
    - $`w=weight`$
    - $`b=bias`$
- ### Activation Function：$`y=f\left(z\right)`$
    - $`y=output`$

# Types of Activation Functions
- ### Linear Activation Function
    - $`f\left(z\right)=az+b`$
